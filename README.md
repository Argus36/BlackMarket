# 🖤 BlackMarket

**BlackMarket** — интернет-витрина с функционалом корзины, избранного, фильтрации товаров и личного кабинета. Учебный проект, разработанный на чистом JavaScript без использования фреймворков.

## 📋 О проекте

Проект представляет собой веб-приложение для просмотра и покупки товаров (учебная симуляция). Реальные финансовые транзакции не осуществляются. Все данные хранятся в `localStorage`.

### Основные возможности

- ✅ Просмотр каталога товаров с фильтрацией по 6 категориям
- ✅ Добавление товаров в корзину (только для авторизованных пользователей)
- ✅ Управление количеством товаров в корзине
- ✅ Оформление заказов с сохранением истории
- ✅ Добавление товаров в избранное
- ✅ Регистрация и авторизация пользователей
- ✅ Авторизация по email или 64-символьному API-ключу
- ✅ Личный кабинет с историей заказов
- ✅ Адаптивная вёрстка (мобильные устройства, планшеты, ПК)
- ✅ Сохранение выбранного фильтра после перезагрузки страницы

## 🚀 Запуск проекта

### Требования

- Любой современный браузер (Chrome, Firefox, Safari, Edge)
- Локальный веб-сервер (для работы ES-модулей)

### Способ 1: Live Server (VS Code)

1. Установите расширение **Live Server** в VS Code
2. Откройте проект в VS Code
3. Нажмите правой кнопкой на `index.html`
4. Выберите **Open with Live Server**

### Способ 2: http-server (Node.js)

```bash
# Установка http-server глобально
npm install -g http-server

# Запуск в папке проекта
http-server

# Откройте браузер по адресу http://localhost:8080
```
